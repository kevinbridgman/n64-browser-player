Now playing

Open the emulator menu to configure keyboard or controller mappings, use save states, and download or restore save backups. For Smash, connect up to four controllers and assign each player in the controls menu.

Before you jump in

Controllers & keyboard

Connect your controller and press a button, then map it in the emulator’s controls menu. Map the analog stick, A/B, C buttons, Z, L/R and Start. Click the game before using the keyboard. Bluetooth and USB controllers depend on browser support.

Keeping your progress

Use the game’s own save feature first. While playing, this page attempts to store cartridge saves every five seconds. Return with the same ROM in the same browser. Download backups from the emulator menu before clearing browser data or switching devices. Save states are separate from in-game saves.

Performance & compatibility

Use a recent Chrome, Edge, Firefox, or Safari with WebGL enabled. Desktop with a controller is recommended; N64 performance and touch support vary by device.
